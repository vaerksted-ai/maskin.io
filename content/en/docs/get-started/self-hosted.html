Self-hosted setup

Run your own Maskin instance and connect Claude — Code or Desktop — to it over MCP, so you can drive a workspace from inside Claude.

! This guide is for the self-hosted version of Maskin — connecting Claude to a Maskin instance you run yourself. Want us to host it instead? Book a meeting.

Prerequisites

  • Claude Code or Claude Desktop installed.
  • An Anthropic API key — Maskin runs Claude Code in sandboxes and uses this key. A fresh instance only accepts it after you set one environment variable (Step 2).
  • A running Maskin instance (set one up below).

Run your Maskin server

Clone the open-source repo, install with pnpm, run pnpm dev. Needs Node 20+, pnpm and Docker.

git clone https://github.com/sindre-ai/maskin.git && cd maskin
pnpm install
pnpm dev

The app opens on port 5173 (http://localhost:5173) and the API runs on port 3000. On first run it bootstraps a dev actor, a workspace, and an API key (printed in the startup banner). For a real deployment, put it behind your own domain (referred to below as https://<your-maskin-host>) and review the configuration reference.

Step 1 — Sign in and create a workspace

  1. Open your instance at http://localhost:5173 (or https://<your-maskin-host>) and sign in.
  2. Create your first workspace when prompted.

Once you're in, you'll see the unified pipeline view: Insights → Bets → Tasks.

Step 2 — Add your Anthropic API key

A fresh instance runs agents on a Maskin-funded model and refuses your own key: saving one returns "This workspace is on the Maskin-provided LLM plan and cannot add BYO LLM credentials", and Settings → LLM keys shows no key fields. To bring your own key, list your user id in MASKIN_ENTERPRISE_ACTOR_IDS first.

  1. Create an API key as in Step 3, then find your user id (the entry with "type": "human"): 
    curl -s http://localhost:3000/api/actors \
  -H "Authorization: Bearer <YOUR_MASKIN_API_KEY>"
  2. Add it to the .env file in the repo root (several ids can be comma-separated), then restart the server: 
    MASKIN_ENTERPRISE_ACTOR_IDS=<your-user-id>
  3. Open Settings → LLM keys, paste your Anthropic API key and Save.

Without this setting, agent sessions need MASKIN_FALLBACK_OPENROUTER_KEY instead and run on the default Maskin-funded model.

Step 3 — Get your Maskin API key and workspace ID

  1. Open Settings → API keys, click Create key, and copy the ank_… value.
  2. Open Settings → Workspace and copy the Workspace ID (a UUID).

Step 4 — Connect Claude to your Maskin MCP

Claude Code

Register the MCP server. The URL of your instance goes after the server name:

claude mcp add --transport http maskin \
  https://<your-maskin-host>/mcp \
  --header "Authorization: Bearer <YOUR_MASKIN_API_KEY>" \
  --header "X-Workspace-Id: <YOUR_WORKSPACE_ID>"

Then reload plugins:

/reload-plugins

Claude Desktop

Open Settings → Developer → Edit config and add the maskin server:

{
  "mcpServers": {
    "maskin": {
      "type": "http",
      "url": "https://<your-maskin-host>/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_MASKIN_API_KEY>",
        "X-Workspace-Id": "<YOUR_WORKSPACE_ID>"
      }
    }
  }
}

Save and restart Claude Desktop.

Step 5 — Make your first MCP call

Ask Claude:

Use the maskin MCP to call get_started.

The get_started tool previews and applies a workspace template — development, growth, or custom — seeding your workspace with object types, statuses, custom fields, and an initial set of objects. See the full tool set in the MCP tools reference.
