Open source alternatives to Jira, Notion, Codex, and more

Every open-source alternative that ranks for “replace Jira,” “replace Notion,” or “self-host an AI SDR” solves cost and hosting around the same object model as the incumbent it copies: a ticket, a page, an outbound queue, a kanban of coding tasks. Maskin is the Apache-2.0, MCP-native workspace where the unit of work is a bet — a testable hypothesis with a win condition, owned jointly by a human and agents — so the loop from signal to shipped, validated outcome actually closes. The one line that connects all five

Open source is a licence, not a product decision. A permissively licensed clone of a ticket queue, a page tree, an outbound sequencer, or a coding-task kanban reproduces that shape’s ceiling. Maskin’s bet-and-loop object model — insight → bet → task → shipped → validated — is the different shape underneath, expressed as first-class workspace objects a team configures rather than code a developer wires. For the doctrine behind planning in bets rather than backlogs, see bet-based product planning; for the category above these comparisons, see what is an agentic workspace?.

Common threads across every comparison

  • Apache 2.0. Read the behaviour, modify it, run it commercially — a permissive licence, not a look-but-don’t-touch one.
  • MCP-native. The UI, agents, and any Claude/Codex/local-model client talk to one unified object model over one API. See what is MCP-native?
  • Self-host always free. Pay only for your own infrastructure and model usage. See self-hosted AI workspace for the full self-host story.
  • Human-gated loops. Agents bring the signal; humans keep the taste points. Bounded by close conditions and promote gates, not open-ended chat.
