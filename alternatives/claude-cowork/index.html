Claude Cowork alternatives, sorted by the job you need done

The best Claude Cowork alternative depends on the job: use OpenWork or Eigent for one person’s files, a suite agent for work already in Microsoft 365, ChatGPT or Salesforce, and Coworker.ai or Agentforce Coworker for search across tools. For agents sharing a team board, compare Multica with Maskin, which records product work as shared insights, bets and tasks.

This is for you if you lead product or technology at a 200 to 3,000 person company and need to decide whether Cowork is enough for a team, or whether to move agent work into a shared record your company hosts.

Cowork is now part of Claude: what changed, and what still matters

On 16 September 2026, Anthropic announced that Cowork and chat are merging into one Claude. The rollout starts with Pro and Max plans, with Team and Free to follow. The Cowork product page now says “Claude Cowork is now just Claude.” Anthropic’s help center says organizations that have not turned it on keep chat and Cowork as separate options. For Enterprise, Anthropic promised admins at least 30 days’ notice before changes, and said on 23 October that the unified experience is generally available. Cowork is a name in mid-retirement, but teams still use it and people still search for it.

Two familiar complaints need a check against current documentation. Anthropic says cloud sessions, which are in beta, keep working when you close your laptop, and scheduled tasks run in the cloud with no device online. Local desktop sessions still depend on that machine being awake.

For Enterprise, Anthropic says Cowork sessions through Claude, Claude Desktop and Claude Mobile are captured in the Compliance API. Team and Enterprise owners can stream Cowork events through OpenTelemetry. OpenTelemetry does not replace audit logging for compliance. For local sessions, conversation history sits on the user’s computer, where admins cannot centrally manage or delete it. Check these details before switching.

Three reasons to leave still hold:

  1. Cowork runs Claude. Anthropic says it can run where your data lives through Amazon Bedrock, Gemini Enterprise Agent Platform or Microsoft Foundry. That helps with data location, but does not let you choose a different model or run your own.
  2. You cannot host Cowork yourself. It is a product Anthropic ships and runs.
  3. The unit of work is a task, not a shared record. You hand off a task and review the result. A team deciding what to build may also need the signal behind the work, who owns it and whether it worked.

If none of those limits affects your team, stay. Cowork is a good product, and switching has a cost.

For one person’s files: OpenWork and Eigent

OpenWork is a desktop app for macOS, Windows and Linux, powered by OpenCode. Everything outside its enterprise folder is MIT. Its organization control plane, OpenWork Den, has a separate source-available license: free for up to 5 users, free to evaluate for 30 days, and a paid subscription for production use beyond that. Den lets admins publish skills and plugins and assign them to a person, team or organization. OpenWork is local-first, supports 50+ model providers, and can use your keys or local models through Ollama.

Eigent is an Apache 2.0 open-source Cowork desktop built on CAMEL-AI. Its recommended setup is fully local, with local models through vLLM, Ollama or LM Studio. It can run several specialized agents in parallel. It also has a cloud version and an enterprise tier with SSO.

Choose these when the work is one person’s folders, spreadsheets and documents. They can help with individual work, but do not make that work a shared product decision record.

For a company suite: Copilot Cowork, ChatGPT Work, Agentforce Coworker and Coworker.ai

Copilot Cowork runs inside Microsoft 365. Microsoft says it grounds work in your email, meetings and files, pauses for approval before sending an email or making a big update, and runs in a sandboxed cloud environment. Microsoft also says it integrated the technology behind Claude Cowork. Admins enable it in the Microsoft 365 admin center, and billing is usage-based.

ChatGPT Work is OpenAI’s agent for multi-step work and finished deliverables. Work on web and mobile runs in the cloud. The desktop app can use local files and apps with your permission. For shared work, OpenAI’s workspace agents are cloud-run, Codex-powered agents a team builds once and uses in ChatGPT or Slack.

Agentforce Coworker is Salesforce’s assistant and indexes 300+ enterprise sources. Its beta documentation says it can currently update only Salesforce CRM records, and shows a proposed update for review first. Choose it if Salesforce is where your work lives.

Coworker.ai is an independent product, not Anthropic’s. It pitches organizational memory through a permission-aware knowledge graph across 50+ connectors. Each task is routed to a model from OpenAI, Anthropic, Google or open-weight providers. It is also available through MCP inside Claude Code, Cursor and other clients.

Google’s nearest answer is the Gemini Enterprise app. You build agents in its Agent Designer and connect them to Google Workspace, Microsoft 365, HubSpot and Jira. It is a platform for building agents more than a ready-made Cowork equivalent. All four products in this section are closed products.

For a team sharing an agent board: Multica and Maskin

Multica is an open-source workspace where you assign work to AI coding agents as you would to a teammate. Its README lists 26 agent CLIs, including Claude Code, Codex and Cursor. Agents pick up an issue, report progress, raise blockers and hand the result back for review. You can self-host with Docker Compose or Helm, and it provides an execution log and per-run token usage. The license is Apache 2.0 plus extra conditions: internal use inside one organization is fine, but offering it as a hosted service to third parties requires a commercial license.

Maskin is an Apache 2.0, self-hostable workspace where humans and agents share typed records. Work enters as an insight from Slack, Intercom, PostHog, GitHub, Gmail or a scheduled scan. Someone shapes it into a bet, a testable hypothesis with a win condition. The bet breaks into tasks, which agents run in isolated sessions: Claude Code CLI by default or Codex CLI, each inside an ephemeral microVM. When work ships, the outcome is checked against the win condition. See what an agentic workspace is.

The unit of work is the key difference: Multica’s issue ends at a pull request; Maskin’s decision ends at a verdict. Maskin is the wrong pick if you need a personal-files agent, want to bring any model, or need local models, which are not validated. It supports Claude Code or Codex CLI only. Memory across conversations is a known gap, and self-hosting needs an agent-server host that runs the microsandbox and libkrun runtime. It is early: the public repo had 7 stars and 410 open issues and pull requests on 27 October 2026, compared with Multica’s about 54,000 stars. Judge the architecture, not the track record. Read the note on agent memory across sessions.

When OpenWork or Multica stops fitting

OpenWork may stop fitting when one person’s agent worked well and now three people need the same results. OpenWork Den can share skills and connections across a team, so distribution is not necessarily the gap. The question is what the team can read afterwards. Its README describes skills, plugins, MCP connections and access control, not a record of what was decided, who owned it or whether it worked.

Multica may stop fitting when the work is not an issue, such as a pricing decision, a research question or a support pattern that should become a product bet. Its README describes issues, runs and review gates, not a verdict on whether the work met its goal. Another reason to reconsider is licensing: offering a hosted agent service to your customers requires a commercial agreement first.

How to choose in five questions

  1. Whose files are they? One person’s files point to a desktop agent. A team’s work is not a desktop-agent job.
  2. Which suite do you already live in? If it is Microsoft 365, ChatGPT, Salesforce or Google, try that suite’s own agent first.
  3. Must you pick or host the model? If yes, consider OpenWork, Eigent or a self-hosted team workspace.
  4. Are you doing tickets that end as pull requests, or decisions that end as outcomes? Tickets point to Multica. Decisions point to Maskin.
  5. Who has to read the result? If only you, a desktop agent may be enough. If a team, an auditor or next quarter’s you needs it, you need records.

Illustration, not a customer story: A six-person product team runs a weekly competitor scan. Today, one person pastes results into a document. A desktop agent speeds that person up, but the scan is still in a document nobody opens. In a shared workspace, the scan creates insights, a person promotes one into a bet, agents draft the work as tasks, and the team can later see whether the bet won.

What moving a team off Cowork looks like for a head of product or CTO

  1. Start with one recurring job.
  2. Keep the same Claude Code and Codex CLIs. Maskin runs those same CLIs, so the move is about where the work is recorded.
  3. Put that work in shared records rather than treating it only as a task handed off for review.
  4. See whether the team reads the records.

FAQ

What is the best alternative to Claude Cowork?

There is no single best alternative. For one person’s files, compare OpenWork and Eigent. For work inside a company suite, try its own agent first. Coworker.ai or Agentforce Coworker fit search across tools. For agents on a team board, compare Multica and Maskin, especially whether your work ends in a pull request or a product decision and verdict.

Is there a free alternative to Claude Cowork?

OpenWork’s app and core are MIT, and Eigent is Apache 2.0. Maskin and Multica are free to self-host under their stated licenses. Free software does not mean there is no operating cost: model usage or the machine still has a cost. Check each license, especially Multica’s extra conditions on offering a hosted service to third parties.

Is there an open source alternative to Claude Cowork?

For one person’s files, OpenWork and Eigent are open-source options. For teams, compare Multica and Maskin. Multica’s license is Apache 2.0 text with extra conditions, including a restriction on offering it as a hosted service to third parties without a commercial license. Maskin is Apache 2.0, but is early and has a known memory gap across conversations.

Is there a ChatGPT alternative to Claude Cowork?

ChatGPT Work is OpenAI’s agent for multi-step work and finished deliverables. Work on web and mobile runs in the cloud, while the desktop app can use local files and apps with your permission. OpenAI’s workspace agents are cloud-run, Codex-powered agents that a team builds once and uses in ChatGPT or Slack.

Is Microsoft Copilot Cowork the same as Claude Cowork?

No. Copilot Cowork runs inside Microsoft 365, and Microsoft says it integrated the technology behind Claude Cowork. It grounds work in Microsoft 365 email, meetings and files, pauses for approval before sending an email or making a big update, and runs in a sandboxed cloud environment. Admins enable it in the Microsoft 365 admin center.

Is Codex similar to Claude Cowork?

Partly, but they are not the same product. Codex is OpenAI’s coding agent, and Codex CLI is one of the command line agents Maskin can run. Claude Cowork is an autonomous task agent for knowledge work. If your work is tickets that end as pull requests, compare coding-agent workspaces such as Multica rather than treating Codex as a direct Cowork replacement.

Can Claude Cowork be self-hosted?

No. Claude Cowork is a product Anthropic ships and runs. Anthropic says it can run where your data lives through Amazon Bedrock, Gemini Enterprise Agent Platform or Microsoft Foundry. Those options help with data location, but do not let you host Cowork yourself or choose a different model to run in it.

How is Multica different from Maskin?

Multica assigns issues to coding agents, with work that ends at a pull request. Maskin shares typed product records, including insights, bets and tasks, with a decision that ends at a verdict. Their licenses also differ: Multica’s Apache 2.0 text has extra conditions, including a limit on offering it as a hosted service to third parties without a commercial license.

Can I bring my own model to Maskin?

Maskin runs the Claude Code CLI by default or the Codex CLI. It does not support choosing any model directly, and local models are not validated. If local models or a broad choice of providers matter, OpenWork supports 50+ model providers, your own keys and local models through Ollama.

Is Maskin mature?

Not yet. As of 27 October 2026, its public repo had 7 GitHub stars and 410 open issues and pull requests, compared with Multica’s about 54,000 stars. Memory across conversations is also a known gap. Treat Maskin as an early option, and judge whether its shared record model fits your work rather than assuming it has an established track record.
