What a loop is on Maskin

A loop is an outcome, not a feature. Each of the pages above walks through a real closed cycle that produces a real result — a live SEO page, a booked meeting, a cited wiki answer — on Maskin's typed object graph. The loop is what closes; the agents, MCPs, and skills behind it are named honestly on each loop page so you can copy the shape.

The ambient agent workspace is the substrate all of these loops run on. If you want to understand the object model beneath before picking a loop, start there.
