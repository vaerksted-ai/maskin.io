What a flow is on Maskin

A flow is an outcome, not a feature. Each of the pages above walks through a real closed cycle that produces a real result — a live SEO page, a booked meeting, a qualified lead with the rejection reason on record, a cited wiki answer, a month of receipts gathered into one reviewed draft (page in Danish), a shipped bet mapped back to the signal that motivated it — on Maskin’s typed object graph. The flow is what closes; the agents, MCPs, and skills behind it are named honestly on each flow page so you can copy the shape — see how agent skills work in Maskin for the packaged-judgment layer these flows attach to their agents.

The ambient agent workspace is the substrate all of these flows run on. If you want to understand the object model beneath before picking a flow, start there.
