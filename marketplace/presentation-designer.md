# AI presentation designer for finished decks
Hire a presentation designer that builds your deck as one file and checks it before it hands it over.

## What an AI presentation designer is
An AI presentation designer is an agent that builds presentation decks. Presentation Designer is a digital employee hired for that one job. It searches your workspace for an existing design style, asks how dense the slides should be, and checks the story before it designs. It delivers the finished deck as one HTML file that fits laptop, tablet and phone screens, and checks it by opening it at each screen size.

## The job
Presentation Designer takes on the deck-building job inside your workspace. It owns one outcome: a finished deck as one file. It searches knowledge pages, files and brand notes for an existing design style, then tells you what it found and asks you to confirm. If it finds no style, it asks for a link, a file, or a few words describing one. It asks how dense the slides should be, checks the story before designing, and builds the deck.

## What happens when you install
1. It opens a chat in your direct messages and says hello.
2. It looks through your workspace for a design style.
3. If it finds one, it says what it found and asks you to confirm. If not, it asks for a link, a file, or a few words about the style.
4. When you give it a style, it saves it as a knowledge page called “Design style”, so the next deck starts from it.
5. You ask for a deck. It builds it as one HTML file that fits laptop, tablet and phone screens, and checks it by opening it at each screen size.

## What it needs from you
- A style, if it finds none: a link, a file, or a few words.
- An answer on how dense the slides should be.
- It needs a model key if your workspace has none (it says so in its first message) and a computer of its own to open the deck. Without a computer, the deck arrives marked “not visually checked”.

## Key takeaways
- A digital employee hired for one job: building decks.
- The finished deck is one HTML file, opened and checked at each screen size.
- It looks for your design style in knowledge pages, files and brand notes, and saves the one you give it.
- It checks the deck by opening it at each screen size, and says so when it could not.

## FAQ

### What is an AI presentation designer?
An AI presentation designer is an agent that builds presentation decks. Presentation Designer is a digital employee hired for that job. It works in your workspace, uses a design style found or provided there, checks the story before designing, and delivers the finished deck as one HTML file.

### What does Presentation Designer make?
A deck as one HTML file. Before designing, it asks how dense the slides should be and checks the story. It then checks the finished deck by opening it at each screen size.

### What if it cannot open the deck?
It still delivers the deck, with that screen size marked “not visually checked”. The label tells you the visual check was not completed for that size.

### Does it know my brand?
It searches your knowledge pages, files and brand notes for an existing design style. If it finds one, it tells you what it found and asks you to confirm. If it finds none, it asks for a link, a file, or a few words describing the style.

### What happens to the style I give it?
It saves it as a knowledge page called “Design style”, so the next deck starts from a saved style.
